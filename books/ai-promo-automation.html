결제·다운로드·환불은 각 판매 플랫폼에서 해당 플랫폼의 정책에 따라 진행됩니다.

만든 다음이 더 힘들어서 쓴 책입니다

전자책이나 상품을 만들고 나면 홍보 글 올리기, 댓글 답하기, 반응 확인이 반복됩니다. 이 책은 그 반복 작업을 AI 비서에게 맡기는 방법을, 직접 해 보며 막혔던 지점까지 그대로 담았습니다.

이런 분께 맞습니다

  • 상품은 만들었는데 SNS 홍보 글을 매번 쓰고 올리기 부담스러운 분
  • 컴퓨터가 서툴러도 화면 순서대로 따라 하고 싶은 분
  • 스레드 홍보 글 게시와 댓글 답글 작성을 줄이고 싶은 분
  • AI가 실수하지 않도록 승인 단계와 확인 방법을 알고 싶은 분

이런 분께는 덜 맞습니다

  • AI에게 모든 게시와 답글을 완전 자동으로 맡기려는 분
  • 여러 사이트에서 동시에 대량 게시하는 방법을 찾는 분

준비부터 게시 확인까지 8단계

한 번만 하는 준비와, 홍보할 때마다 반복하는 단계가 나뉘어 있습니다.

  • 프롤로그AI가 대신 홍보 글을 올려준다면

    반복 작업을 맡긴다. 홍보 글 작성과 게시, 이미지 첨부, 댓글 답글 초안까지 무엇을 할 수 있게 되는지 소개합니다.

  • 1~2단계딱 한 번 하는 준비와 작업방 열기

    설치는 한 번이면 끝. Git, 오르카, 클로드 코드 로그인, 작업 폴더를 준비하고 새 워크스페이스를 만드는 순서입니다.

  • 3단계AI 비서와 대화 시작하기

    확인 창에 당황하지 않는다. 처음 뜨는 권한·폴더 신뢰 확인 창마다 어떻게 답할지 순서대로 정리했습니다.

  • 4단계홍보 자료 폴더에 넣기

    AI가 읽을 자료를 먼저 준비한다. 원고, 상세페이지 이미지, 판매 링크 메모를 작업 폴더에 넣는 방법입니다.

  • 5단계브라우저를 대신 움직이게 하기

    확장 프로그램 설치 뒤 새 작업방. /chrome 명령으로 확장 프로그램을 설치하고, 새 워크스페이스를 다시 만들어야 하는 이유를 설명합니다.

  • 6~7단계한마디 요청과 사이트 접근 승인

    댓글은 초안만 받는다. 홍보 글 게시 요청 문장, AI가 되묻는 세 가지, 사이트 접근 승인 옵션의 차이를 다룹니다.

  • 8단계게시 확인과 댓글 관리

    완료 메시지 대신 눈으로 확인한다. 실제 사이트에서 게시를 확인하는 습관과, 댓글 자동 확인 기능을 쓰는 방법을 안내합니다.

3장 (3단계)에서

처음 뜨는 확인 창, 이렇게 답합니다

새 작업방을 만들면 클로드 코드가 자동으로 켜지고 확인 창이 몇 번 뜹니다.

  • "Bypass Permissions mode" 질문: 1번(No, exit)을 고릅니다. AI가 확인 없이 뭐든 실행하는 위험한 모드라, 매번 묻는 방식을 유지하는 편이 좋습니다.
  • 창이 꺼지면 claude 라고 입력해 다시 실행합니다.
  • "이 폴더 신뢰하나요?" 질문: 직접 만든 폴더라면 1번(Yes)을 고릅니다.
5장 (5단계)에서

브라우저 조작 기능 켜는 순서

AI가 SNS 사이트에 접속해 글을 올리려면 브라우저를 조작할 권한이 필요합니다.

  1. 채팅창에 /chrome 이라고 정확히 입력합니다.
  2. "Install Chrome extension"을 선택하고 엔터를 누릅니다.
  3. 크롬 브라우저에서 확장 프로그램 설치를 마칩니다.

확장 프로그램을 설치해도 지금 하던 대화에는 바로 적용되지 않습니다. 반드시 새 작업방을 다시 만들어야 브라우저 조작 기능이 인식됩니다.

6장 (6단계)에서

요청은 한마디, 답글은 초안만

복잡한 문장 없이 사람에게 부탁하듯 말하면 됩니다.

스레드에 홍보 글 자동 게시하고, 댓글 달리면 답글도 도와줘

이후 AI가 접근 방식, 게시할 콘텐츠의 기반 자료, 댓글 처리 방식을 되묻습니다. 댓글 처리는 반드시 "답글 초안만 작성"을 고르라고 책은 권합니다. 실제 손님에게 나가는 답글이 AI 실수로 이상하게 나가는 일을 막아 줍니다.

자주 묻는 질문

코딩을 전혀 몰라도 할 수 있나요?

네. 책에 나온 명령어는 복사해 그대로 입력하는 수준이고, 코드를 직접 작성할 일은 없다고 안내합니다.

AI가 이상한 글을 올리면 어떻게 하나요?

게시처럼 되돌리기 어려운 행동에는 최종 확인 단계가 있습니다. 그 단계를 건너뛰지 말고 내용을 확인한 뒤 승인하라고 안내합니다.

스레드 말고 다른 SNS에도 쓸 수 있나요?

원리는 같습니다. 사이트 이름만 바꿔 요청하면 AI가 시도하지만, 화면 구조가 달라 처음에는 시행착오가 있을 수 있다고 설명합니다.

확인 창이 자꾸 떠서 번거로운데 줄일 수 있나요?

"이번 세션 동안 계속 허용" 옵션으로 같은 작업 안에서는 확인을 줄일 수 있습니다. 다만 완전 자동 모드는 익숙해지기 전까지 권하지 않습니다.

이 책 한 권으로 모든 자동화가 끝나나요?

아닙니다. 책 마지막에도 한 권으로 모든 자동화가 완성되지는 않는다고 밝힙니다. 8단계를 한 번 따라 해 보면 다음 홍보부터 훨씬 빨라진다는 것이 이 책의 설명입니다.
