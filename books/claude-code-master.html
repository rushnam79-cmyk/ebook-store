클로드 코드를 챗봇처럼 쓰지 말고
시스템으로 쓰는 28가지 방법

/init부터 컨텍스트 관리, 서브 에이전트, 훅, 에이전트 팀까지. 초급 9개, 중급 11개, 고급 8개 팁을 실전 프롬프트 예시와 함께 정리한 가이드입니다.

크몽에서 구매하기

결제·다운로드·환불은 각 판매 플랫폼에서 해당 플랫폼의 정책에 따라 진행됩니다.

같은 도구인데 결과가 크게 달라지는 이유

클로드 코드는 '이거 고쳐줘' 한마디만 반복해도 쓸 수 있습니다. 하지만 컨텍스트 관리, 서브 에이전트, 스킬, 훅까지 쓰는 사람과는 결과가 크게 갈립니다. 이 책은 그 격차를 메우는 28가지 방법을 순서대로 정리했습니다.

이런 분께 맞습니다

  • 클로드 코드를 설치했지만 '고쳐줘' 수준으로만 쓰고 있는 분
  • 왜 자꾸 엉뚱한 코드를 짜는지 답답했던 분
  • 서브 에이전트, 스킬, 훅 같은 기능을 어디서부터 써야 할지 모르는 분
  • 혼자서 여러 작업을 병렬로 돌리는 방법을 알고 싶은 분

이런 분께는 덜 맞습니다

  • 코딩과 터미널을 전혀 접해본 적이 없고 설치 방법부터 알고 싶은 분
  • 특정 프로젝트의 코드를 대신 만들어 주는 완성형 결과물을 기대하는 분

초급, 중급, 고급 세 단계로 나눠 28개를 익힙니다

처음이면 1부부터 순서대로, 익숙하다면 목차에서 필요한 팁만 골라 읽으셔도 됩니다.

  • 들어가며클로드 코드란 무엇인가

    챗봇이 아니라 에이전트입니다. 파일을 읽고 쓰고, 명령어를 실행하고, 테스트와 깃 작업까지 처리하는 도구라는 점과, 각 팁이 어떤 순서로 구성되어 있는지 안내합니다.

  • 1부 초급기본기 다지기 (팁 1~9)

    프로젝트 초기화, 컨텍스트 관리, 계획 우선. /init, /statusline, /context, /compact와 /clear, 플랜 모드, 되묻게 만들기, TODO 자가 점검까지 처음 습관으로 만들 9가지를 다룹니다.

  • 2부 중급효율 끌어올리기 (팁 10~20)

    반복을 시스템으로 바꿉니다. 서브 에이전트 병렬 작업, 나만의 스킬, 모델 나눠 쓰기, CLAUDE.md 갱신과 라우터 구성, /rewind, Hooks, 스크린샷과 레퍼런스 활용을 담았습니다.

  • 3부 고급자동화와 확장 (팁 21~28)

    혼자서 여러 사람 몫을 하는 영역. Git Worktree 병렬 세션, MCP 대신 API 호출, /loop 예약 작업, 스마트폰 원격 제어, 자연어 DB 질의, ultrathink, 권한 설정, 에이전트 팀을 설명합니다.

  • 마치며28개 팁을 내 워크플로에 적용하는 법

    한 번에 다 하려 하지 않습니다. 1주차 기본 세팅, 2주차 컨텍스트 관리, 3~4주차 효율화, 그 이후 확장 순서로 나눈 적용 계획을 제안합니다.

  • 부록용어 설명

    처음 보는 용어를 바로 확인합니다. CLAUDE.md, 컨텍스트, 토큰, 플랜 모드, 서브 에이전트, 스킬, Hooks, MCP, Git Worktree 등 책에 나오는 용어를 정리했습니다.

각 파트 끝에 요약 정리 수록 · 부록: 용어 설명

책 속에서 미리 읽어보기

구매 전에 문체와 깊이를 확인하실 수 있도록 본문 일부를 옮겼습니다.

1부 팁 5에서

/compact와 /clear, 언제 무엇을 쓸까

/compact는 지금까지의 대화를 요약해서 컨텍스트를 압축하고, /clear는 대화 기록을 완전히 초기화합니다. 압축은 맥락을 유지한 채 용량만 줄이는 것이고, 초기화는 백지에서 다시 시작하는 것입니다.

상황쓰는 명령
같은 작업을 이어갈 때/compact
완전히 새로운 작업을 시작할 때/clear

버그 하나를 다 고친 뒤 새 기능 개발로 넘어갈 때 /clear로 시작하면, 이전 맥락이 새 작업에 섞이지 않습니다.

2부 팁 11에서

반복 작업은 나만의 스킬로 저장하기

자주 반복하는 작업을 SKILL.md 형태로 저장해 두면, 다음부터는 스킬 이름만 불러서 항상 같은 방식으로 쓸 수 있습니다. 매번 '이런 형식으로, 이런 순서로 해줘'를 설명하는 대신 한 번 잘 정의한 절차를 재사용하는 방법입니다.

지금 우리가 방금 완성한 '주간 리포트 작성 절차'를 스킬로 저장해줘. 이름은 weekly-report로 하고, 다음부터는 '이번 주 리포트 작성해줘'라고만 해도 똑같은 구조로 나오게 해줘.
마치며에서

28개를 한 번에 적용하지 않는 순서

28가지를 한 번에 적용하려 하면 어느 것도 습관이 되지 못합니다. 책은 다음 순서를 권합니다.

  1. 1주차 기본 세팅: 팁 1, 2, 6. 모든 프로젝트에 /init, 상태줄 설정, 플랜 모드로 시작
  2. 2주차 컨텍스트 관리: 팁 3, 4, 5, 9
  3. 3~4주차 효율화: 팁 10~14, 16. 병렬 서브 에이전트와 스킬화, CLAUDE.md 라우터 구조
  4. 그 이후 확장: Git worktree, 예약 작업, 권한 설정, 에이전트 팀을 필요에 따라 하나씩

클로드 코드를 처음 쓰는데 읽어도 되나요?

1부 초급이 처음 쓰는 분을 기준으로 쓰여 있습니다. 다만 설치 방법을 설명하는 책은 아니고, 이미 쓸 수 있는 상태에서 더 잘 쓰는 방법을 다룹니다.

순서대로 다 읽어야 하나요?

아닙니다. 처음이면 1부부터 따라가시고, 익숙하다면 목차에서 필요한 팁만 골라 읽어도 됩니다.

개발자가 아니어도 도움이 되나요?

예시는 코드 작업 중심입니다. 스킬, CLAUDE.md, 예약 작업처럼 일반 업무에도 적용할 수 있는 내용이 있지만, 코딩 경험이 없으면 이해하기 어려운 팁도 있습니다.

읽으면 바로 생산성이 오르나요?

보장할 수는 없습니다. 28개를 한 번에 적용하기보다 주차별로 나눠 하나씩 습관으로 만드는 것을 책도 권합니다.

기능 이름이나 명령어가 바뀌면 어떻게 되나요?
